# Pour-over Mentor – Android-App

V60-Brühcoach mit Bluetooth-Waage (Acaia Pearl, Bookoo Themis Ultra/Mini), Sprachansagen und lernendem Mahlgrad.

## Herunterladen

**[pour-over-mentor.apk](https://github.com/andresliechti/pour-over-mentor-app/raw/main/pour-over-mentor.apk)** – aktuelle Version siehe `version.json`.

## Installieren (Android)

1. Den Link oben auf dem Handy öffnen. Chrome lädt die Datei herunter.
2. Auf die fertige Datei tippen (Benachrichtigung oder «Downloads»).
3. Beim ersten Mal fragt Android, ob Chrome Apps installieren darf: **«Aus dieser Quelle zulassen»** einschalten, zurück, **Installieren**.
4. Falls «Play Protect» warnt: **«Trotzdem installieren»**. Die App ist nicht im Play Store, deshalb kennt Google sie nicht.
5. Beim ersten Start die Bluetooth-Berechtigung («Geräte in der Nähe») erlauben.

## Updates

Die App prüft beim Start, ob es eine neuere Version gibt, und zeigt dann oben «Update available». Tippen → herunterladen → installieren. Die Daten bleiben erhalten.

Diese Seite enthält nur die fertige App, keinen Code und keine Daten.
